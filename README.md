# Anomaly-Detection
(PT) Um bot do Discord para a comunidade que gosta do gênero terror.

  Este bot do Discord serve para analisar imagens e estimar a probabilidade de uma figura presente nela ser humana ou uma possível criatura sobrenatural. O projeto foi desenvolvido como parte de um curso de programação e tem como inspiração jogos de terror e detecção de anomalias.

🔍   Para a utilização do bot, envie a imagem que deseja que seja analisada junto com o comando '$check' que o bot dará uma porcentagem indicando se a figura na imagem é natural ou uma entidade.   ⚙️

🛠️  Ainda está em desenvolvimento, novos comandos e respostas serão adicionados futuramente.

⚠️  Este projeto é apenas para fins de entretenimento para histórias entre grupos de usuarios que gostam de jogos de terror de anomalias. O bpt ainda é bem limitado na interpretação de imagens, há chances de que cometa erros em respostas.
